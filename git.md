# Подсказки по GIT

## Первая команда
```sh
git init
```

## Логи
```sh
git log
```

## Логи в одну строку
```sh
git log --onleline
```

## Сохранить
```sh
git add <filename>
```

## Узнать стату файлов 
```sh
git status
```

## Добавить сообщение
```sh
git commit -m "сообщение"
```

## Переключение между сохранениями
```sh
git checkout
```
