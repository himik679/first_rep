# Подсказки по GIT

### Первая команда
```sh
git init
```

### Логи
```sh
git log
```

## Логи в одну строку
```sh
git log --onleline
```

### Сохранить
```sh
git add <filename>
```

### Узнать стату файлов 
```sh
git status
```

### Добавить сообщение
```sh
git commit -m "сообщение"
```

### Переключение между сохранениями
```sh
git checkout
```

## Ветки

### Создание ветки 
```sh
git branch название
```

### Переместится на ветку 
```sh
git checkout название
```

### Слить ветки
```sh
Перейти в ветку, в которую будет происходить слияние и написать git merge название ветки, из которой будет слияние
```

### Удаление веток
```sh
git branch -D название ветки
```

## Github

### Скачивание файла по ссылке
```sh 
git clone ссылка
```

### Отправление файла в интернет
```sh
git push
```

### Скачивание обновленного файла
```sh
git  pull
```
