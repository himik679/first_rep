# Подсказки по GIT


## Общее 

### Первая команда
```sh
git init
```

### Логи
```sh
git log
```

### Логи в одну строку
```sh
git log --onleline
```

### Сохранить
```sh
git add название файла
```

### Узнать стату файлов 
```sh
git status
```

### Добавить сообщение
```sh
git commit -m "сообщение"
```

### Переключение между сохранениями
```sh
git checkout
```
## Ветки

### Посмотреть ветки
```sh
git branch
```

### Создать ветку
```sh
git branch название
```

### Перейти на ветку
```sh
git checkout название ветки
```

### Удалить ветку
```sh
git branch -D название ветки
```
